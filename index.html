03 · Churn analysis

Waze Churn Prediction

Explored how to identify Waze app users at risk of churn. Churned users drove more per driving day but used the app on fewer days.

Practice project Fictional teaching dataset from the Google Advanced Data Analytics Certificate

Tools

  • Python
  • Hypothesis testing
  • Logistic regression
  • Random Forest
  • XGBoost

Finding 18% of users churned. XGBoost recall was 17%, compared with 9% for logistic regression.

Next step A second model iteration with more data and better features.
